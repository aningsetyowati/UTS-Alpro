Tentang Platform AlproHub

Platform web ini dikembangkan sebagai media pembelajaran dan dokumentasi terstruktur untuk mata kuliah Algoritma dan Pemrograman. Melalui web ini, mahasiswa dapat menyimpan, menganalisis, serta menguji implementasi beragam studi kasus algoritma mulai dari pencarian, pengurutan, hingga struktur data.

Penyimpanan Otomatis

Semua data studi kasus yang ditambahkan tersimpan langsung di browser (LocalStorage).

Multi-Bahasa Kode

Mendukung C++, Python, Java, dan JavaScript dengan tombol salin instan.

Panduan Penggunaan Cepat
  • Gunakan fitur Pencarian untuk menemukan studi kasus berdasarkan algoritma atau kata kunci.
  • Klik tombol "Baca Solusi" pada kartu studi kasus untuk membaca analisis lengkap dan menyalin kode.
  • Klik tombol "+ Tambah Studi Kasus" di navigasi atas untuk menambah studi kasus atau tugas baru Anda.
  • Gunakan fitur Export / Import JSON untuk mem-backup atau membagikan kumpulan studi kasus ke teman.
